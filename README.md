# AlertRes: App de Búsqueda y Rescate de Personas Desaparecidas (2026)
### Alumna: **Naiara Gadea Rodríguez Gómez**  
Este repositorio recoge los documentos del Trabajo de Fin de Máster del [Máster en Ingeniería Biomédica y Salud Digital](https://www.mibsd.us.es/) de la [Universidad de Sevilla](https://www.us.es/) realizado por Naiara Gadea Rodríguez Gómez. En este repositorio se recogen todos los ficheros del TFM, cuyo objetivo es el desarrollo de una aplicación multiplataforma de apoyo en la búsqueda y rescate de personas desaparecidas.


## **Resumen**
Este trabajo se centra en la exploración de una solución a una necesidad real, proponiendo una aplicación multiplataforma que sirva de apoyo en la búsqueda y rescate de personas desaparecidas. Esta aplicación se basará en un sistema de alertas y geolocalización. Desde la aplicación se fomenta la mejora de la gestión de los operativos de búsqueda y la colaboración ciudadana y entre los distintos grupos de búsqueda con el fin de encontrar a la persona desaparecida en el menor tiempo posible. 

Durante el desarrollo del proyecto se han estudiado los distintos aspectos teóricos alrededor de la problemática de las personas desaparecidas. Asimismo, se ha indagado en las soluciones disponibles actualmente para definir las características que debería tener la aplicación. Además, se propone a lo largo del proyecto, de forma teórica, un sistema de predicción de zonas de localización de víctimas en base a los datos de las personas desaparecidas. Por otro lado, se ha realizado un prototipo con funcionalidades básicas utilizando Visual Studio Code, MariaDB, ReactNative, JavaScript y Node.js.

Toda la información y ficheros LaTeX de la memoria y el prototipo creado a lo largo del trabajo en este repositorio de GitHub.


## **Abstract**
This work focuses on exploring a solution to a real need by proposing a cross-platform application to support the search and rescue of missing persons. This application will be based on an alert and geolocation system. The app promotes improved management of search operations and citizen cooperation, as well as collaboration among different search groups, with the aim of locating the missing person in the shortest possible time.

During the project development, the various theoretical aspects surrounding the problem of missing persons were studied. Likewise, currently available solutions were investigated in order to define the features the application should have. In addition, the project theoretically proposes a system to predict likely victim location areas based on missing-person data. On the other hand, a prototype with basic functionality was created using Visual Studio Code, MariaDB, React Native, JavaScript, and Node.js.

All the information and LaTeX files for the report and the prototype created during this work are in this GitHub repository.


## **Objetivos**
La problemática de las personas desaparecidas es un problema internacional y que supone un gran impacto a nivel social. Aunque existen multitud de herramientas que facilitan la labor de los buscadores e investigadores ante una desaparición, la autora de este trabajo no tiene conocimiento de ninguna que integre todo el proceso de búsqueda y la colaboración activa entre FFCCS, otros grupos y ciudadanía, para encontrar a una persona desaparecida.

De acuerdo con ello, el **objetivo principal de este trabajo es el de diseñar una aplicación de apoyo en la búsqueda y rescate de personas desaparecidas**. Para conseguir dicho fin, se han establecido una serie de subobjetivos a cumplir en este trabajo:
- **Subobjetivo 1. Estudio del contexto actual**.
- **Subobjetivo 2. Estudio de herramientas actuales**.
- **Subobjetivo 3. Descripción y diseño de la aplicación**.
- **Subobjetivo 4. Definición y obtención de un prototipo**.
- **Subobjetivo 5. Bases de un sistema de predicción**.

\subsection{Requisitos Previos}
\textcolor{red}{REVISAR}

Como lo realizado es solo un prototipo, es necesario tener instalado\footnote{Ante cualquier problema siguiendo los siguientes pasos, por favor ponerse en contacto conmigo para intentar solucionarlos, a tráves del correo nairodgom@alum.us.es}:
\begin{itemize}
    \item MariaDb con su interfaz HeidiSQL para poder crear las tablas y la base de datos que he usado para almacenar la información. En la imagen \ref{diagrama_tablas} se pueden observar todas las tablas creadas en la base de datos alertres.

    \item Node.js

    \item Visual Studio Code con la extensión ESLint.
\end{itemize}

\figura{0.7}{img/DiagramaClases_Tablas.png}{Diagrama de las tablas creadas para la base de datos de AlertRes. \textit{Fuente propia.}}{diagrama_tablas}{keepaspectratio}


Después, recomiendo descargar la carpeta AlertRes disponible en el repositorio de GitHub creado para el proyecto \url{https://github.com/NaiaraGadea/TFM_AppBusquedaYRescate/} y abrirla desde Visual Studio Code

se deberá modificar el archivo .env en función de la contraseña que se ha puesto al crear la base de datos y los archivos api.js y server.js en función del ip del wifi utilizado. Para averiguar la dirección IP en Windows se abre el terminal y se escribe el comando ipconfig y se busca la IP de la red LAN:
\figura{0.7}{img/ipconfig.png}{Dirección IP necesaria para el backend. \textit{Fuente propia.}}{web_inicio0}{keepaspectratio}

Seguidamente tendremos que activar el backend con la línea de código:

npm run start:backend

Si todo va bien deberemos ver:

AlertRes API escuchando en http://localhost:4000

Después activaremos el Frontend pero esta vez:

cd Frontend

npx expo start --clear \footnote{Si da problemas usar npm install antes}

una vez aparezcan las opciones para abrir nuestra aplicación, yo recomiendo usar la web, ya que es mucho más rápida y no suele dar problemas, para ello pondremos 'w' y debería abrirse una pestaña en el navegador donde al cabo de unos segundos se muestra nuestra aplicación lista para su suo.

    \subsection{Interacción con la base de datos}

    En la base de datos creada con MariaDB, alertres, se tienen diferentes tablas con las que interaccionará la aplicación. Una tabla que registrará los datos de personas desaparecidas, missing persons. Otra que registrará la información básica del caso donde se incluye la fotografía de la persona, cases. Otra que registrará las alertas que se han activado, alerts. Otra donde se registra la información de las búsquedas organizadas para encontrar a una persona, searchs. (Y la tabla de registro de usuarios)

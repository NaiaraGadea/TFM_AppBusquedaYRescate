\cdpchapter{Resumen}

\textcolor{red}{En este trabajo se presenta la creación e implementación de una aplicación multiplataforma que sirve de apoyo en la búsqueda y rescate de personas desaparecidas. Desde la aplicación se fomenta la mejora de la gestión de los operativos de búsqueda y la colaboración ciudadana y entre los distintos grupos de búsqueda. (Para el desarrollo de la app se ha empleado React Native, Node.js, Javascript). Además, se presenta (de forma teórica) una pequeña mejora donde utilizar los datos de las personas desaparecidas recogidos con la app para predecir las zonas donde se podrían encontrar a futuras víctimas. }

Este trabajo se centra en la exploración de una solución a una necesidad real, proponiendo una aplicación multiplataforma que sirva de apoyo en la búsqueda y rescate de personas desaparecidas. Esta aplicación se basará en un sistema de alertas y geolocalización. Desde la aplicación se fomenta la mejora de la gestión de los operativos de búsqueda y la colaboración ciudadana y entre los distintos grupos de búsqueda con el fin de encontrar a la persona desaparecida en el menor tiempo posible.

Durante el desarrollo del proyecto se han estudiado los distintos aspectos teóricos alrededor de la problemática de las personas desaparecidas. Asimismo, se ha indagado en las soluciones disponibles actualmente para definir las características que debería tener la aplicación. Además, se propone a lo largo del proyecto, de forma teórica, un sistema de predicción de zonas de localización de víctimas en base a los datos de las personas desaparecidas.

Por otro lado, se ha realizado un prototipo con funcionalidades básicas utilizando Visual Studio Code, MariaDB, ReactNative, JavaScript y Node.js.

Toda la información y ficheros LaTeX de la memoria y el prototipo creado a lo largo del trabajo en el repositorio de GitHub: \url{https://github.com/NaiaraGadea/TFM_AppBusquedaYRescate}.

\cdpchapter{Abstract}

This work focuses on exploring a solution to a real need by proposing a cross-platform application to support the search and rescue of missing persons. This application will be based on an alert and geolocation system. The app promotes improved management of search operations and citizen cooperation, as well as collaboration among different search groups, with the aim of locating the missing person in the shortest possible time.

During the project development, the various theoretical aspects surrounding the problem of missing persons were studied. Likewise, currently available solutions were investigated in order to define the features the application should have. In addition, the project theoretically proposes a system to predict likely victim location areas based on missing-person data.

On the other hand, a prototype with basic functionality was created using Visual Studio Code, MariaDB, React Native, JavaScript, and Node.js.

All the information and LaTeX files for the report and the prototype created during this work are in the GitHub repository: \url{https://github.com/NaiaraGadea/TFM_AppBusquedaYRescate}.
